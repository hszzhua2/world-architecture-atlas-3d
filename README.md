A 3D world architecture museum on an interactive map — explore 10 iconic landmarks from around the globe rendered as 3D models at their real-world geographic coordinates.

Built on top of [GeoLibre](https://github.com/opengeos/GeoLibre), an open-source cloud-native GIS platform, with a custom Three.js rendering layer that places procedurally-generated GLB building models onto a MapLibre GL JS map.

---

## Overview

World Architecture Atlas 3D transforms a 2D map into an interactive 3D architecture museum. Click the **Landmarks** button in the toolbar and the map flies to Paris, tilts to a 60-degree perspective, and renders 10 world-famous buildings as 3D models — each positioned at its exact real-world location.

## Features

- **3D Building Models** — 10 procedurally-generated landmark models (GLB format) built with Three.js geometry primitives, each accurately positioned at its real-world GPS coordinates using `MercatorCoordinate.fromLngLat`.
- **Custom MapLibre Layer** — A Three.js-powered custom layer that shares the map's WebGL context, rendering 3D models in sync with pan, zoom, and rotate operations.
- **Cinematic Fly-To** — Clicking the Landmarks button triggers a smooth 4-second flight animation to the first landmark (Eiffel Tower) with a 60-degree pitch for a dramatic 3D perspective.
- **GIS Data Integration** — Natural Earth vector datasets (airports, urban areas, populated places) loaded as additional map layers for geographic context.
- **Full GeoLibre Suite** — Inherits all of GeoLibre's GIS capabilities: layer management, style editing, attribute tables, SQL workspace, and more.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 20+
- npm 10+

### Installation

```bash
# Clone the repository
git clone https://github.com/hszzhua2/world-architecture-atlas-3d.git
cd world-architecture-atlas-3d

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173/`.

### Usage

1. Open the app in your browser.
2. Click the **Landmarks** button (landmark icon) in the top toolbar.
3. The map will fly to Paris and display the Eiffel Tower in 3D.
4. Pan, zoom, and rotate to explore all 10 landmark models at their real-world locations.
5. Use the **Add Data** button to load additional GIS datasets (Natural Earth GeoJSON files are included in `public/data/`).

### Regenerating 3D Models

The landmark GLB models are procedurally generated by `generate-landmarks.mjs`. To regenerate them:

```bash
node generate-landmarks.mjs
```

This script uses Three.js's `GLTFExporter` to build simplified architectural models from basic geometry primitives (boxes, cylinders, cones, spheres) and exports them as binary glTF (`.glb`) files to `apps/geolibre-desktop/public/models/`.

## How It Works

### 3D Rendering Pipeline

The 3D landmark system uses a **MapLibre GL JS custom layer** backed by **Three.js**:

1. **Model Generation** — `generate-landmarks.mjs` builds each landmark from Three.js geometry primitives (no external 3D assets required) and exports them as GLB files.

2. **Geographic Positioning** — Each model is placed at its real-world coordinates using `MercatorCoordinate.fromLngLat()`, which converts longitude/latitude to Mercator world space. The `meterInMercatorCoordinateUnits()` method scales model dimensions from meters to Mercator units.

3. **Coordinate Transform** — A composite matrix applies translation (position), rotation (Y-up to Z-up axis conversion), and scale, aligning the model with the map's surface.

4. **Shared WebGL Context** — The Three.js `WebGLRenderer` reuses MapLibre's canvas and GL context, so 3D models render directly on top of the base map without a separate overlay.

5. **Camera Sync** — On each frame, MapLibre's `modelViewProjectionMatrix` is applied to Three.js's camera, keeping the 3D models in perfect sync with the map's pan, zoom, pitch, and bearing.

### Why Three.js Instead of deck.gl?

GeoLibre includes deck.gl for 3D visualization, but deck.gl's `loaders.gl` URL-loading pipeline was receiving Vite's SPA fallback HTML instead of the GLB binary data. The Three.js custom layer bypasses this by using `GLTFLoader` directly, which correctly fetches and parses GLB files.

## Adding Custom Landmarks

To add your own 3D models:

1. **Create a GLB model** — Use Blender, Three.js, or any glTF-compatible tool to create a `.glb` file. Author the model in meters with Y-up.

2. **Add it to `public/models/`** — Place the `.glb` file in `apps/geolibre-desktop/public/models/`.

3. **Register the landmark** — Add an entry to the `WORLD_LANDMARKS` array in `apps/geolibre-desktop/src/lib/load-landmarks.ts`:

   ```typescript
   {
     name: "Your Building",
     lng: longitude,
     lat: latitude,
     modelFile: "your-model-file-name",  // without .glb extension
     sizeScale: 3,  // multiplier for model size
   },
   ```

4. **Reload and click Landmarks** — The new model will load alongside the existing ones.
